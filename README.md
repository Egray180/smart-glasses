# EyeWhere
This repository contains the files for smart glasses developed by Ethan Gray and Connor Salpeter. All of the relevant files are present with the exception of the PCB design files, which can be found [here](https://github.com/Egray180/smart-glasses-pcb).
For detailed documentation of our methodologies and design choices check our [System Report](System%20Report.pdf), and for instructions to get a pair working see [Assembly & Operation Instructions](Assembly%20%26%20Operation%20Instructions.pdf).
